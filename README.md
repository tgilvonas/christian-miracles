This is mini wiki of Christian miracles and Christian saints. Developed on Laravel 12 and Vue 3.

Installation:
1. Build Docker container if you want to dockerize your local copy
2. Run composer install
3. Configure database connection in your .env file (copy from .env.example)
4. Execute command "php artisan key:generate"
5. Execute command "php artisan migrate"
6. Execute command "php artisan db:seed"
7. Execute command "npm install"
8. Execute command "npm run build"
9. Log into CMS, create content and spread The Gospel
